# AuraCard 补丁说明（1.0.1 / 2026-08-08）

相对 `v1.0.0-2026-08-08` 的桌面端稳定性补丁。不含密钥与大体量二进制。

---

## 一、Mac「打包下载全部」卡住

**相关文件：** 导出 / Electron 下载路径相关改动（见提交 `31d64f7`、`40aa19f`）

## 二、API Key 持久化

- 修复密钥输入后未可靠自动保存的问题，重启应用后仍可读取已保存配置。

## 三、项目与正文保存

- 修复保存项目 / 正文时偶发未落盘的问题，保证编辑内容可稳定写回。

- 版本号 bump 至 **1.0.1**。
