# AuraCard v1.0.2（2026-08-09）

相对 `v1.0.0-2026-08-08b`。含未单独发版的 1.0.1 稳定性修复 + 本轮功能/UI。

## 本轮亮点

- **中栏工具条紧凑**：编辑 / 添加页 | 保存文字·项目·重置 | 下载卡片▾ 单行分组，窄屏干净换行。
- **表格排版**：点击单元格调列对齐、列宽、列顺序；导出保留。
- **按页导出**：下载菜单可勾选页面后下 PNG / ZIP。
- **AI 草稿一键排版**：整理结果可编辑后再写入卡片。
- **保存入口统一**：中栏保存文字 / 保存项目与主操作同排。
- **稳定性（原 1.0.1）**：Mac 打包下载修复、取消下载、API Key 持久化、项目/正文保存。

## 下载说明

- **Windows**：`AuraCard-1.0.2-x64-setup.exe`（安装包）、`AuraCard-1.0.2-x64-portable.exe`（便携版）
- **macOS**：`AuraCard-1.0.2-mac-arm64.dmg` / `.zip`，`AuraCard-1.0.2-mac-x64.dmg` / `.zip`（CI 未签名；若无法打开请右键 → 打开）
