# AuraCard v1.0.3（2026-08-10）

相对 `v1.0.2-2026-08-09`。

## 本轮亮点

- **封面文字菜单**：独立文字层编辑（字号/字体/颜色），可拖动定位后导出。
- **导出子菜单**：封面导出设置 popover，支持标准高清 / 4K。
- **智能浮层**：菜单自动避让顶栏与侧栏，按空间落位。
- **提示 UI 统一**：各处说明文案统一为 `ui-hint`。
- **返回主页**：图文 / 封面等非首页顶栏统一入口。

## 下载说明

- **Windows**：`AuraCard-1.0.3-x64-setup.exe`（安装包）、`AuraCard-1.0.3-x64-portable.exe`（便携版）
- **macOS**：`AuraCard-1.0.3-mac-arm64.dmg` / `.zip`，`AuraCard-1.0.3-mac-x64.dmg` / `.zip`（CI 未签名；若无法打开请右键 → 打开）
